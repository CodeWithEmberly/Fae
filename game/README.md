# Tradewinds 1522

An original age-of-sail trading game for the browser, built phone-first.
Open `index.html` in any browser, or play it from GitHub Pages once merged.

**How to play:** buy goods where they're green (cheap), sail them to a port
where they're red (dear), sell, repeat. Keep food and water stocked, patch
the hull, hire crew, and reach 200,000 gold.

- Tap the sea to set a course; drag to pan; + / − to zoom; ◎ to find your ship.
- The game autosaves in your browser.
- World: a half-degree grid of the Atlantic and Mediterranean, 21 ports.
